Sửa xong, cuộn xuống cuối trang để lưu. Trang này KHÔNG hiển thị công khai trên menu — chỉ ai có đường dẫn mới vào được, nhưng vẫn nên giữ kín link này.

Mỗi dịch vụ tự có 1 trang chi tiết riêng trên web (không cần tạo tay). Ảnh Trước/Sau sẽ hiện dạng kéo qua kéo lại — dùng ảnh thật của khách đã đồng ý công khai.

Thêm bao nhiêu bác sĩ tuỳ ý — mỗi người hiện thành 1 thẻ riêng ở trang Giới thiệu.

Danh sách chi nhánh ở đây cũng chính là danh sách để khách chọn khi đặt lịch ở trang Liên hệ.

Giờ mở cửa

Dán link ảnh (Unsplash, ảnh tự upload, kể cả link xem file GitHub) vào từng ô bên dưới để thay ảnh tương ứng trên web.

Ảnh slideshow Trang chủ

Mỗi bài viết tự có trang riêng. Ô "Nội dung": để 1 dòng trống giữa các đoạn văn để web tự tách đoạn.

1. Cách đơn giản — tải file rồi tự thay lên GitHub

Bấm nút bên dưới để tải file clinic-data.js mới, sau đó vào GitHub → mở file assets/clinic-data.js → bấm biểu tượng cây bút → xoá hết nội dung cũ → dán nội dung file mới vào → Commit.

2. Cách nhanh hơn — lưu thẳng lên GitHub bằng 1 nút bấm (nâng cao)
Cần tạo "Personal Access Token" trên GitHub 1 lần. Token giống như mật khẩu — không chia sẻ, không dùng máy công cộng. Token chỉ dùng cho trình duyệt này, không được lưu lại.
