Chứng chỉ / cam kết

1. Cách đơn giản — tải file rồi tự thay lên GitHub

Bấm nút bên dưới để tải file clinic-data.js mới, sau đó vào GitHub → mở file assets/clinic-data.js → bấm biểu tượng cây bút → xoá hết nội dung cũ → dán nội dung file mới vào → Commit.

2. Cách nhanh hơn — lưu thẳng lên GitHub bằng 1 nút bấm (nâng cao)
Cần tạo "Personal Access Token" trên GitHub 1 lần (xem hướng dẫn Claude gửi kèm bên dưới khung chat). Token giống như mật khẩu — không chia sẻ, không dùng máy công cộng. Token chỉ dùng cho trình duyệt này, không được lưu lại.
